# Sakola – School Landing Page

A responsive school landing page built with **HTML5** and **CSS3**. This is a static front-end portfolio/practice project.

## Features
- Responsive layout for desktop, tablet, and mobile screens
- Hero, About, Schools, Courses, Newsletter, and Footer sections
- Local images, icons, and course illustrations
- Accessible skip link and visible keyboard-focus styles
- Reduced-motion support
- No build tools or package installation required

## Technologies
- HTML5
- CSS3
- Google Fonts (loaded online)

## Run Locally
1. Extract or clone this repository.
2. Open the `Sakola` folder in VS Code.
3. Open `index.html` in a browser, or use the **Live Server** extension.

## Publish with GitHub Pages
1. Push the project files to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder, then save.
5. Wait for GitHub Pages to publish the site; the URL will appear in the Pages settings.

## Notes
- This is a static front-end demonstration. Sign-in, sign-up, and newsletter links are demo links and are not connected to a backend.
- Replace the sample contact email and social links with your own details before publishing.
- Google Fonts requires an internet connection; local layout and images remain in the repository.
